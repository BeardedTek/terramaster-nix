Once your NAS is installed and running, this is where to find everything
about actually using it day to day.

- **[LLDAP](/docs/usage/lldap/)** — the one directory behind every login
  on this box, and how to manage users.
- **[WebUI](/docs/usage/webui/)** — the dashboard: logging in and out,
  the home page, the services list, and System Preferences.
- **[Available Services](/docs/usage/services/)** — what's running, how
  it's set up, and where to go for detailed usage of each one.
